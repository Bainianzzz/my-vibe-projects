# my-vibe-projects

[中文](README.md) · English

A just-in-time flash of inspiration 🌟

- [douyin-pic-spy · Douyin image post downloader](https://github.com/Bainianzzz/douyin-pic-spy): A Douyin image-post downloader userscript that supports both single-post and batch downloads.
- [resume-writer · Job Application Quick-Fill Assistant](https://github.com/Bainianzzz/resume-writer): A Tampermonkey userscript built on vite-plugin-monkey. It learns field-to-answer pairs from a form you fill in by hand, then autofills other application pages in one click. Fields that local matching misses are passed to Jev (TypeSafe's structured decision model) for semantic matching.
